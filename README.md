# Inclusive Health Open House Trivia

A lightweight, browser-based trivia game branded for Inclusive Health's Open House. It includes 15 randomized questions about the clinic, its services, Dr. Joanne Thambuswamy, and Clinical Director Tara Weidner.

## Play
Open `index.html` in a browser, or enable GitHub Pages for the repository to run it as a website.

## Room codes and late joining
- Starting a game with a blank room field creates a 6-character room code.
- The room code and a **Scan to Join** QR code stay visible while trivia is in progress.
- Guests who scan the QR are taken back to the game with that room code already filled in.
- Guests can also manually enter the room code shown on the game screen.
- Everyone using the same room code receives the same randomized question order.
- This build is still independent play: progress, answers, scores, and the local leaderboard are stored on each device rather than synchronized live between devices.

## Features
- Inclusive Health branding and logo
- 15 multiple-choice questions
- Room-based deterministic question order
- Scan-to-join QR code for late arrivals
- Instant answer explanations
- Score tracking and progress bar
- Local top-10 leaderboard by room (stored only in that browser)
- Responsive layout for a TV, tablet, laptop, or phone
- Confetti for high scores

## Trivia sources
Question facts were based on Inclusive Health's public website (homepage, Clinical Team, Admin Team, Plans & Costs) plus clinic information supplied by Inclusive Health.

Built for the Inclusive Health Open House.
